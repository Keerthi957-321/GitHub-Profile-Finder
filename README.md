# 🔍 GitHub Profile Finder

A simple, responsive web application that allows you to search for GitHub profiles in real-time using the official GitHub REST API.

---

## 🚀 Live Demo

Check out the live application here: **[Live Demo Link](https://YOUR_LIVE_DEMO_URL.com)**

---

## ✨ Features

- **Real-Time Search:** Instantly fetch any public GitHub account by username.
- **Profile Overview:** View avatar, bio, followers, following, and public repo counts.
- **Top Repositories:** Lists the user's latest public repositories with links.
- **Responsive Layout:** Works smoothly on mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API:** [GitHub REST API](https://github.com)
